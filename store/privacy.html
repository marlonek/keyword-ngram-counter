Privacy Policy — Keyword n-gram counter

Last updated: 23 October 2026

Keyword n-gram counter ("the add-on") is designed to be privacy-preserving by default.

What data we collect

None. The add-on does not collect, store remotely, transmit, sell, or share any personal data, spreadsheet data, or usage data. There are no analytics, no telemetry, no tracking, and no cookies.

How the add-on works

The add-on runs entirely inside Google Sheets, on the current spreadsheet only. When you run an analysis, it reads the cells you selected (or the text you pasted into the sidebar), counts repeated phrases, and writes the results to a new tab in the same spreadsheet. This processing happens in your spreadsheet and the results never leave it. The add-on makes no network requests of its own.

Permissions and why they are needed

  • Access to the current spreadsheet only (spreadsheets.currentonly) — to read the cells you select and write the results table into the same spreadsheet. It never accesses any other spreadsheet.
  • Show the sidebar UI (script.container.ui) — to display the add-on's interface inside Google Sheets.

Data sharing

We do not sell or transfer user data to third parties, and we do not use user data for any purpose unrelated to the add-on's single purpose (counting repeated phrases in your text).

Changes to this policy

If this policy changes, the updated version will be published at the same location with a new "Last updated" date.
